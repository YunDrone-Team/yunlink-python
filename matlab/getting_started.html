YunLink MATLAB 快速开始

下载发布包即可，不必克隆代码仓库：

yunlink-sunray-matlab-1.2.0-bundle.zip

1. 准备 Python

在 Windows、macOS 或 Linux 上安装 Python 3.10、3.11、3.12 或 3.13。不要使用 MATLAB 自带的 3.14。需要的是可执行文件路径，例如：

Windows:  C:\Users\<用户>\AppData\Local\Programs\Python\Python313\python.exe
macOS:    /opt/homebrew/bin/python3.13
Linux:    /usr/bin/python3.12

2. 安装 Toolbox

不要在 Add-On Explorer 中搜索本工具箱。解压发布包后，双击 yunlink-sunray-matlab-1.2.0.mltbx，在安装器中点击 Install。不要使用 Add Package Repository。

3. 配置一次

yunlink_examples

打开 ex00_setup.m，填写 pythonExe 和 bundleDir，点击 Run。然后按 ex01_discover.m、ex02_connect_and_inspect.m、ex03_watch_state.m 的顺序运行。完整列表见 examples/README.md。

4. 连接并读取状态

client = yunlink_connect("192.168.31.236:9696");
uav = yunlink_vehicle(client, "e-f97f96-2-1");
state = yunlink_state(uav);
disp(state.position);
disp(state.batteryPercent);
disp(state.armed);
disp(state.landed);

5. 基础控制

yunlink_takeoff(uav, 1.5);
yunlink_position_control(uav, 2.0, 0.0, 1.5);
yunlink_hover(uav);
yunlink_land(uav);
yunlink_close(client);

完整说明见 README.md。
