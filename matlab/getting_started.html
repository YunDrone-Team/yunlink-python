YunLink MATLAB 快速开始

下载发布包即可，不必克隆代码仓库：

yunlink-sunray-matlab-1.4.5-bundle.zip

用 MATLAB 学本工具箱的办法：按编号跑 example，打开脚本看注释。不要先抄下面的函数。

1. 准备 Python

在 Windows、macOS 或 Linux 上安装 Python 3.10、3.11、3.12 或 3.13。不要使用 MATLAB 自带的 3.14。需要的是可执行文件路径，例如：

Windows:  C:\Users\<用户>\AppData\Local\Programs\Python\Python313\python.exe
macOS:    /opt/homebrew/bin/python3.13
Linux:    /usr/bin/python3.12

2. 安装 Toolbox

不要在 Add-On Explorer 中搜索本工具箱。解压发布包后，双击 yunlink-sunray-matlab-1.4.5.mltbx，在安装器中点击 Install。不要使用 Add Package Repository。

3. 教程：yunlink_examples

yunlink_examples

打开 ex00_setup.m，填写 pythonExe 和 bundleDir，点击 Run。然后按编号往下。完整表格见 examples/README.md。

编号脚本会发控制学什么
00ex00_setup.m否配 Python，装通信库
01ex01_discover.m否搜索 Bridge，抄连接地址和 entity_uid
02ex02_connect_and_inspect.m否连接，只看目录
03ex03_watch_state.m否attach，只读状态。fresh=1 才能飞
04ex04_flight_basics.m会飞起飞约 1 m，短移，降落
05ex05_cancel_action.m会飞取消动作
06ex06_ugv_control.m会走无人车点位 / 速度 / Hold
07ex07_errors.m可能失败起飞看错误信息
08–11多 Bridge / 多机只读否选 Bridge、刷遥测
12ex12_live_check.m会飞/会走现场全量检查

目标写在 yunlink.env，不要改脚本中间的变量。填 entity_uid，不要填 uav1。

4. 看完 example 后再自己写

client = yunlink_connect("192.168.31.236:9696");
uav = yunlink_vehicle(client, "e-f97f96-2-1");
state = yunlink_state(uav);
yunlink_takeoff(uav, 1.5);   % 1.5 是相对高度，单位米
yunlink_hover(uav);
yunlink_land(uav);
yunlink_close(client);

自己写脚本时查阅 API.md。逐步说明书的 Typst 源码见 docs/README.md，可自行编译 PDF；GitHub Release 提供 yunlink-matlab-manual.pdf。
